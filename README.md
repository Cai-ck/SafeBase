## Sobre o Projeto
 O SafeBase é uma plataforma de gerenciamento e vitrine de jogos personalizada. 

 O projeto consiste em uma aplicação web estruturada para centralizar títulos de interesse, progresso de gameplay e documentação técnica de jogos (guias e reviews).

 Este projeto faz parte de um estudo dirigido focado em Arquitetura de Software Front-end, com o objetivo de criar um ecossistema escalável que permita futuras integrações com ambientes Desktop e Mobile.

 ## 🛠️ Arquitetura e Funcionalidades
 O sistema foi projetado seguindo o princípio de separação de responsabilidades, utilizando uma estrutura de dados desacoplada para facilitar a manutenção. 

  - **Landing Page (Home):** Dashboard principal com exibição dinâmica de títulos em destaque, segmentados por estados (ex: Último zerado, Em progresso ou Favoritos).

 - **Library (Biblioteca):** Módulo de listagem completa com sistema de filtragem avançada por categorias, gêneros e status de conclusão.   
 
 - **Game Details (Página do Jogo):** Visualização detalhada do recurso selecionado, integrando: Consumo de mídia externa (Embedded Trailers via YouTube API).        
 
 Galeria de capturas (Screenshots de autoria própria e assets oficiais).

 Data Bank: Repositório de informações técnicas, reviews e guias de gameplay.

## 🚀 Tecnologias Utilizadas
 A stack tecnológica foi escolhida para consolidar os fundamentos do desenvolvimento web moderno:   
 
 - **HTML5:** Estruturação semântica de dados.   
 
 - **CSS3:** Estilização modularizada (utilizando Variáveis CSS e Grid/Flexbox).   
 
 - **JavaScript (Vanilla):** Manipulação dinâmica do DOM e lógica de roteamento.   
 
 - **JSON:** Utilizado como persistência de dados local (Mock API) para simular o comportamento de um banco de dados relacional.    
 
 Nota de Evolução: O projeto foi arquitetado de forma a permitir uma migração futura para bibliotecas de componentes como React, visando ganho de performance e reuso de estados.
